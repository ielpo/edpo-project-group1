## Agent skills

### Issue tracker

Issues are tracked in GitHub Issues. See `doc/agents/issue-tracker.md`.

### Triage labels

Issues use default triage labels: `needs-triage`, `needs-info`, `ready-for-agent`, `ready-for-human`, `wontfix`. See `doc/agents/triage-labels.md`.

### Domain doc

Single-context repository with `CONTEXT.md` at the root and ADRs in `doc/adr/`. See `doc/agents/domain.md`.
